# Снимок текущих проверок

`verification.json` подтверждает 189 символов, оси, геометрию TTF/WOFF2
и набор текста для указанного SHA-256. `current-quality.json` содержит
все 3402 сочетания символа, веса и размера и цепочку обновлений.
`latest-change.json` — последняя принятая правка модели; `viewer-verification.json`
— историческая проверка элементов просмотра на весах 100 и 900,
не проверка геометрии текущего TTF.

`reproducibility.json` подтверждает побайтовое совпадение TTF/WOFF2 после
сборки из чистого экспорта исходников.

Это снимок результатов, не доказательство полной готовности шрифта.
Указанные внутри JSON пути `build/` относятся к локальным исходным аудитам;
многочисленные PNG и промежуточные сборки в Git не включены.
Повторная сборка: команды в [README](../README.md); полный растровый аудит
на macOS: `python scripts/audit-full-charset.py`.


`design-status.json` связывает готовность контрольной основы и авторского
выпуска с текущим TTF. Невыполненные решения D01–D06 остаются открытыми;
успешная техническая сборка не закрывает их автоматически.

`releases/0.0.1-baseline.json` фиксирует завершённую контрольную основу,
хеши файлов и доказательств в теге `v0.0.1`. Рядом сохранены настройки
растрового аудита и проверка того, что смена версии затронула только метаданные.
`interface-corpus.json` проверяет переносы и границы набора в фиксированном
корпусе; визуальные сравнения светлой и тёмной тем нужны отдельно.
