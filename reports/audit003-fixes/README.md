# Исправления после независимой матрицы 003

Подтверждённое переполнение демонстрационной страницы исправлено. Проверка Chrome прошла в16 сочетаниях ширины320/375/768/1280px, базового текста16/32px и светлой/тёмной темы. Раскрытый RU/EN-текст, управление образцом и обратная связь работают. Текст статьи и UI увеличивается, точный пиксельный образец сохраняет обозначенный размер. Шесть состояний таймера имеют одинаковую ширину текста во всех16 условиях.

Бинарные файлы0.0.3 не менялись. Независимая сборка умеренного варианта побайтно совпала с TTF и WOFF2. Все189 символов и обе оси сохранены. Параллельные отдельные сборки слабого и сильного вариантов проверены без замены `dist/`.

## Что изменено

- Заголовок переносится, сетки допускают сужение, контролы и подписи перестраиваются по содержимому. Глифовые ячейки учитывают увеличение текста.
- Таблица локально прокручивается, доступна с клавиатуры и имеет название области; суммы не разбиваются внутри числа. Горизонтальная прокрутка документа не используется для сокрытия ошибок.
- Точный размер ползунка явно отделён от масштабируемых примеров. Подпись статьи использует1rem вместо обещания неизменных16px.
- В существующем разделе чтения добавлен раскрываемый RU/EN-текст. Новых публичных калибровочных страниц нет.
- README уточняет применение Thin/Black, tabular-nums, конфликт pnum/tnum и пределы различимости O/0. Не расширяет договорённый набор.
- D02–D06 привязаны к текущему TTF через свежую идентичную сборку, независимые текущие отзывы и побайтную проверку геометрии/вариаций208 нетабличных глифов. Изменение10 табличных цифр и40 добавлений контекстных классов проверено отдельно.
- D01 оставлен открытым: сохранность кривых не доказывает различимый характер в строке. Авторский gate по-прежнему закрыт; старые флаги не перенесены автоматически.
