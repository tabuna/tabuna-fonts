# Инструменты измерения и проверки

Основной шрифт собирается командой `python scripts/build.py` из корня проекта.
В выпуске 189 символов; параметры моделей находятся в `sources/`, геометрия —
в `scripts/`. Этот пакет содержит измерения, подбор параметров и проверки.

- `measure_*.py`, `fit_*.py`: калибровка семейств по скалярным измерениям.
- `compare_weight_audits.py`, `check_font_impact.py`: проверка изменений рисунка и области их влияния.
- `check_contour_crossings.py`, `proof_*.py`: проверки контуров и набора.
- `merge_quality.py`: обновление полного отчёта по проверенному изменению.

Сырые результаты, PNG, кандидаты и контрольные копии создаются в `build/`
и не публикуются в Git. Снимок текущих результатов находится в `reports/`.
Измерение относительно SFNS требует macOS; обычная сборка его не читает.

Старые `build_variable.py`, `generate_font.py`, `alphabet.py`, `model.py`
и `data/` относятся к отклонённой экспериментальной пересборке. Они сохранены
для воспроизводимости исследования и не вызываются основной сборкой.
[Историческая документация](../docs/research/REJECTED-REBUILD.md).

При растровом подборе вызывайте `scratch.require_free_space` перед созданием
очередного варианта: при свободном месте меньше 2 ГиБ подбор останавливается.
После сохранения численных результатов `scratch.retain_trial_artifacts`
оставляет PNG и TTF только для исходного и лучшего вариантов. Полный журнал
параметров сохраняется в JSON. Сгенерированные UFO-мастера промежуточных
сборок можно удалять после проверки: они восстанавливаются из Python/JSON.
Исходники, итоговые аудиты и контрольные точки при такой очистке сохраняются.


`refine_family.py` выполняет ограниченный растровый подбор скалярных
параметров собственной модели. Он пишет только в `build/font-recovery/`,
оставляет исходный и лучший варианты и не обновляет выпуск автоматически.
`native_refinement.py` проверяет точное совпадение исходных мастеров,
сохраняет метрики и существующее число квадратичных сегментов.
`native_batch.py` собирает пакетный запуск из текущего `scripts/render-pairs.swift`;
отдельный исторический исполняемый файл для этого не требуется.

`python -m font_recovery.design_status` показывает оставшиеся случаи и
обязательные решения; режимы `--require baseline` и `--require authorial`
служат проверками готовности соответствующего выпуска. Исходные проверки
этого механизма: `python -m unittest font_recovery.test_design_status`.
