# Инструменты измерения и проверки

Основной шрифт собирается командой `python scripts/build.py` из корня проекта.
В выпуске 189 символов; параметры моделей находятся в `sources/`, геометрия —
в `scripts/`. Этот пакет содержит измерения, подбор параметров и проверки.

- `measure_*.py`, `fit_*.py`: калибровка семейств по скалярным измерениям.
- `compare_weight_audits.py`, `check_font_impact.py`: проверка изменений рисунка и области их влияния.
- `check_contour_crossings.py`, `proof_*.py`: проверки контуров и набора.
- `merge_quality.py`: обновление полного отчёта по проверенному изменению.

Сырые результаты, PNG, кандидаты и контрольные копии создаются в `build/`
и не публикуются в Git. Снимок текущих результатов находится в `reports/`.
Измерение относительно SFNS требует macOS; обычная сборка его не читает.

Старые `build_variable.py`, `generate_font.py`, `alphabet.py`, `model.py`
и `data/` относятся к отклонённой экспериментальной пересборке. Они сохранены
для воспроизводимости исследования и не вызываются основной сборкой.
