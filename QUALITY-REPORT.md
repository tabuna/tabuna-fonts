# Качество Tabuna Sans

Текущая сборка **0.0.3 предназначена для пилотного внедрения** в интерфейсах,
заголовках и экранном тексте. Техническая корректность проверена; длительное
чтение и узнаваемость собственного характера пока не подтверждены испытаниями
с людьми. Агентные отзывы не являются мнением Apple или названных дизайнеров.

## Практические ограничения

- Thin 100 не подходит для мелкого важного текста; Black 900 требует проверки
  просветов в плотном наборе. Начальные настройки: 400–500 для UI, 400 для абзацев.
- В критичных идентификаторах нужно отдельно проверять различимость `O/0`.
- Для отсутствующих символов нужен fallback; полный набор ограничен 189 знаками.
- Табличные цифры не заменяют десятичное выравнивание сумм разной точности.
- Мобильные настройки увеличения текста, разнообразные физические экраны
  и длительное чтение с участниками ещё требуют проверки.

## Готовность авторского дизайна

Решения D02–D06 повторно проверены для текущего TTF. **D01 остаётся открытым**:
сохранность математической модели не доказывает узнаваемость характера в строке.
Поэтому проверка готовности авторского выпуска пока возвращает отказ.
