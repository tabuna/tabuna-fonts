# Inter исключён из основной сборки

Текущая задача — собственная компактная параметрическая гарнитура, близкая к SFNS.
Производная Inter была ошибочным завершением задачи и отозвана.
Ниже — история эксперимента, не описание текущей версии.

---

# Текущее решение: Inter как открытая основа

13 сентября 2026 пользователь разрешил сменить подход: «я разрешаю все!
главное результат». Прежнее ограничение на использование Inter как основы
снято. Tabuna Sans 1.000 основан на закреплённом Inter 4.1, с явным
указанием происхождения и сохранением OFL. Готовая сборка находится в dist/.

Ниже — историческая оценка до этого решения; она не описывает текущую сборку.

---

# Inter как технический пример для ускорения старта

Проверено 2026-09-11. Уточнение пользователя: «мы не должны копировать!
мы можем подглядеть!». Последующее уточнение: подсмотреть именно код и
техническое устройство для быстрого старта. Ограничение «только визуально»
было неверной интерпретацией и снято. Конечная цель остаётся 100% совпадения
с системным Apple; Inter не является целевым рисунком.
Авторские исходники и файлы в `dist/` независимы от Inter. Начатый по неверной
интерпретации эксперимент с производной версией остановлен; скрипт и загруженные
исходники Inter удалены. Производный шрифт не был собран.

## Измерение

Официальный Inter 4.1 без изменений сравнивался с текущей Tabuna Sans 0.300
и нативным системным шрифтом Apple `.SFNS-Regular`. Для каждого кандидата
отрисованы те же 98 символов, Regular 400, размеры 16 и 64 pt, масштаб 2×.
Используется один CoreText/CoreGraphics-конвейер, одинаковые начало строки,
базовая линия и сглаживание. Изображения не совмещаются после отрисовки.
Каждый шрифт получает оптический размер, ограниченный диапазоном его оси:
для Inter это 14–32, для Tabuna — 9–72. Настройки и SHA-256 записаны в отчёты.

| Размер | Tabuna: средний ink IoU | Inter: средний ink IoU | Полных совпадений Inter |
| --- | ---: | ---: | ---: |
| 16 pt | 65,43% | 79,02% | 0 из 98 |
| 64 pt | 63,90% | 76,07% | 0 из 98 |

Ink IoU — сумма общего покрытия краской, делённая на сумму объединённого
покрытия. Белый фон не повышает результат. Это среднее сходство изолированных
символов, а не процент качества или готовности; кернинг строк здесь не измерен.
Самопроверка рендера идентичного системного символа проходит во всех отчётах.
Результат относится к этой macOS и этим настройкам, не ко всем платформам.

Данные и пары PNG:

- [Inter, 16 pt](../../proofs/baseline-inter-16/comparison.json)
- [Tabuna, 16 pt](../../proofs/baseline-tabuna-16/comparison.json)
- [Inter, 64 pt](../../proofs/baseline-inter-64/comparison.json)
- [Tabuna, 64 pt](../../proofs/baseline-tabuna-64/comparison.json)

Исторические ключи `tabuna` и суффикс `-tabuna.png` в формате отчёта обозначают
испытуемый шрифт. В каталогах `baseline-inter-*` это Inter; точное имя находится
в `customPostScriptName`, а цветовая легенда использует фактическое имя.

## Что изучаем

В загруженной прямой вариативной версии Inter — 2937 глифов, 2852 Unicode,
`wght` 100–900 и `opsz` 14–32. Есть кернинг, позиционирование диакритик,
табличные цифры, локализованные формы и другие OpenType-возможности.
Исходники проекта доступны в Glyphs-формате; предусмотрен экспорт редактируемых
UFO и Designspace. Диапазон Inter `opsz` нельзя выдавать за самостоятельно
спроектированные мастера 9–72.

Изучаем код сборки, организацию совместимых мастеров, параметров, оптической
оси, имён и OpenType-таблиц, чтобы не искать технические решения с нуля.
Готовые контуры Inter не переносятся; производная гарнитура не создаётся.
Прочитаны Makefile, gen-var-designspace.py и bake-vf.py выпуска 4.1.
В собственной реализации сохраняем явно заданные имена экземпляров,
проверку осей и направление контуров, не копируя код этих инструментов.

Сравнение по пикселям полезно для поиска отклонений. Перед выпуском нужны
также проверки строк на русском и английском, малых размеров, промежуточных
весов, диакритики и реальных браузеров. Ни базовый Inter, ни эта проверка
не гарантируют точного совпадения с SF Pro.

OFL 1.1 разрешает использование, изменение и распространение с сохранением
лицензии и copyright. Производный шрифт остаётся под OFL; его нельзя продавать
самостоятельно. Для производной версии используется собственное название,
как требует также README Inter, указывающий Inter как Reserved Font Name.
Происхождение от Inter должно быть отражено в документации и метаданных.
Такая лицензия не является разрешением от пользователя на копирование:
производный путь в этом проекте отклонён.

Файлы Inter сохранены отдельно в `references/inter/` и пока используются
только для оценки. Сборка `scripts/build.py` не читает этот каталог.
