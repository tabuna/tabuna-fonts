# Независимая реконструкция З, 3 и 2 — 11 сентября 2026

В рабочие TTF/WOFF2 включены три новых самостоятельных контура. Они восстановлены
из растровых эталонов каждого символа: `З` не наследует цифру `3`, а `3` не
наследует `З`. Параметры всей гарнитуры не менялись.

## Принятые результаты

64 pt, вес 400, масштаб 2×, CoreText/CoreGraphics, общий origin и baseline.
Ink IoU учитывает полутоновое покрытие; FP/FN считаются при фиксированном пороге
0.5 для обеих масок. Совмещение изображений после рендера не применяется.

| Глиф | Ink IoU до → после | FP до → после | FN до → после | Крупнейший FN до → после |
|---|---:|---:|---:|---:|
| З | 0.739157 → **0.981768** | 134 → **14** | 491 → **24** | 207 → **2** |
| 3 | 0.716332 → **0.984307** | 209 → **16** | 483 → **25** | 301 → **3** |
| 2 | 0.688691 → **0.983270** | 573 → **6** | 264 → **17** | 115 → **3** |

BBox `З`: **[69,128,134,221]**; bbox `3`: **[70,128,133,221]**.
Оба совпадают с эталоном. Среднее симметричное расстояние между контурами:
`З` **1.410518 → 0.117704 px**, `3` **1.536112 → 0.102880 px**.
Hausdorff: **7.907585 → 0.599215 px** и **7.828392 → 0.534149 px** соответственно.

Составная ошибка использует прежние веса `1−IoU + 2 FN/N + FP/N + 4 Lcontour + 2 Lbbox`:
N — площадь эталонной маски, расстояния нормированы диагональю bbox.
У `З` она снизилась **0.801664 → 0.049175**, у `3` — **0.880092 → 0.049785**.

Каждый глиф измерен отдельно до объединения. Последовательность общего среднего
Ink IoU для 126 контрольных символов на 32/64/128 pt:

| Изменение | Средний Ink IoU |
|---|---:|
| Контроль после предыдущей реконструкции з | 0.899557 |
| Только З | 0.901447 |
| З + 3 | 0.903532 |
| З + 3 + 2 | **0.905928** |

Средние после обоих изменений: 32 pt **0.902875**, 64 pt **0.903608**,
128 pt **0.904113**. Это среднее отдельных оценок, не IoU всей строки.
Совпадение всей гарнитуры пока не достигнуто.

## Проверенные варианты

Все варианты сравнивались с одним определением маски при 0.5. Порог в таблице
определяет только исходную линию уровня для построения геометрии.

| Глиф | Порог построения | Ink IoU пилота | FP | FN | Решение |
|---|---:|---:|---:|---:|---|
| З | 0.25 | 0.940840 | 151 | 0 | Лишнее покрытие, верх bbox отличается на 1 px |
| З | **0.50** | **0.977691** | **22** | **26** | Выбран; bbox и топология совпадают |
| З | 0.75 | 0.931959 | 0 | 132 | Теряется край штриха |
| 3 | 0.25 | 0.932386 | 144 | 1 | Лишнее покрытие, верх bbox отличается на 1 px |
| 3 | **0.50** | **0.973614** | **33** | **26** | Выбран; bbox и топология совпадают |
| 3 | 0.75 | 0.925520 | 0 | 160 | Теряется край штриха |

Три реконструкции вместе с измерением заняли примерно **0.67 s** для `З` и
**0.97 s** для `3`. Это время пилота одного размера, не полной сборки и проверок.

Для каждого глифа использованы 17 смысловых ориентиров на его собственной
упорядоченной границе. Совместимое разбиение добавляет узлы в местах максимальной
измеренной ошибки среди мастеров. Результат: **33 кубических сегмента у З**,
**38 у 3**; одинаковая структура внутри шести опорных рисунков каждого символа.
Рисунки построены для весов 100/400/900 и текстовой/дисплейной оптики.

## Изолированная проверка и область изменений

- Для каждого глифа проверено 25 сочетаний: веса 100/400/900 на
  9/14/16/20/32/64/128 pt, веса 250/700 на 16/64 pt. Во всех случаях IoU вырос.
  Минимальные новые значения: `З` **0.888682**, `3` **0.891479**.
- Векторная топология во всех этих случаях: один замкнутый связный контур, без
  отверстий. При малых размерах и тонких весах порог 0.5 может разбивать штрих на
  отдельные пиксельные островки; различия их количества записаны в JSON-отчётах.
- `2`: отдельный контур с 28 сегментами выбран после порогов 0.25/0.5/0.75.
  Пилот 64 pt/400 дал `0.688691 → 0.982882`; после совместимых мастеров и
  вариативной сборки — `0.983270` в точном контрольном запуске. FP `573 → 6`,
  FN `264 → 17`, крупнейшая FP `391 → 3`. Все 25 проверенных сочетаний осей улучшились.
- Производственная контрольная сборка для `2` собиралась отдельно с отключённым
  новым контуром, поэтому сравнение не включает уже принятые `З/3` в разницу.
- Итоговый `scripts/verify.py`: **40 проверок пройдено, 0 ошибок**. Три численных
  регрессионных теста извлечения и аппроксимации границы также прошли. Эти проверки
  формата, шейпинга, метрик и геометрии не снимают отдельное предупреждение об изломе
  `3`, описанное ниже.
- Все прежние advances и идентификаторы публичных глифов сохранены. Геометрия
  и вариации остальных базовых символов не изменены.
- Табличный вариант `3` следует новому рисунку; шейпинг `tnum` и одинаковая ширина
  десяти цифр проверены на шести сочетаниях размера и веса.
- У `³` и `¾` обнаружилось автоматическое наследование нового рисунка. На тонкой
  `³` при 64 pt это ухудшило IoU **0.130018 → 0.103742**. Этот побочный эффект
  устранён: прежний рисунок сохранён в приватном компоненте `three.small`.
  Геометрия `³/¾` совпадает с контрольной на 25 сочетаниях осей, а 12 нативных
  растровых пар совпали пиксель в пиксель. Публичное покрытие Unicode не расширялось;
  внутренний компонент добавлен в конец порядка глифов.

## Оставшееся замечание по 3 и условие остановки

Проверка fontTools с координатами осей выявляет потенциальный излом в точке **84**
между Thin Text и Regular Text. Это соединение сегментов **27/28** в зоне среднего
окончания. Причина — разное соотношение длин направляющих. Для `З` аналогичных
предупреждений нет.

Проверены ровно три изменения одной входящей направляющей Regular Text. Изменение
не превышало 2 px в нативном рендере 16 pt/2×. Замеры ниже выполнены на исходном
увеличенном захвате 16 pt/32×, отдельно от основной таблицы 64 pt/2×.

| Изменение направляющей | Ink IoU | FP | FN | Итог |
|---|---:|---:|---:|---|
| До коррекции | **0.985254** | 249 | 285 | Сохранён |
| Полное выравнивание отношения длин | 0.985134 | 249 | 289 | Отклонено |
| Половина смещения | 0.985212 | 249 | 287 | Отклонено |
| 70% смещения | 0.985195 | 249 | 288 | Отклонено |

Все три устраняли предупреждение, но ухудшали совпадение маски. Автоматический
перебор остановлен; эти коррекции **не включены**. Принят исходный лучший контур,
поскольку он улучшает контрольный рисунок во всех проверенных случаях и сохраняет
топологию. Предупреждение остаётся открытым, а не объявляется исправленным.

Дополнительный нативный тест в зоне максимального предсказанного отклонения,
вес 175 / 16 pt: **0.548027 → 0.917153**. Для ручной проверки подготовлены
`build/bowl-reconstruction/0033/manual-join-points.json` и `join-review.svg`.
Оригинальный вектор эталона неизвестен; однозначное восстановление и IoU=1
не заявляются.

## Файлы и воспроизведение

- `sources/reconstructed-bowls.json` — принятые независимые мастера;
- `build/bowl-reconstruction/0032/pilot-report.json` — три варианта для `2`;
- `build/bowl-reconstruction/0417/pilot-report.json` и `0033/pilot-report.json` —
  три исходных варианта;
- `build/bowl-reconstruction/proof-0417/report.json` — изолированная проверка З;
- `build/bowl-reconstruction/proof-0033/report.json` — изолированная проверка 3;
- `build/bowl-reconstruction/derived-preserved/report.json` — сохранение ³ и ¾;
- `build/bowl-reconstruction/comparison.png` — две карты до/после;
- `build/full-score.json` — итог контрольного алфавита.

```sh
./.venv/bin/python scripts/reconstruct-bowls.py З pilot
./.venv/bin/python scripts/reconstruct-bowls.py З fit
./.venv/bin/python scripts/reconstruct-bowls.py 3 pilot
./.venv/bin/python scripts/reconstruct-bowls.py 3 fit
```

Эти команды создают кандидаты и отчёты, не заменяя принятые исходники автоматически.
Рабочая сборка: `scripts/build.py`; проверка геометрии, метрик и формата:
`scripts/verify.py`. Проверка `3` относительно сохранённой версии с одной З:

```sh
./.venv/bin/python scripts/proof-bowls.py 3 --control build/bowl-reconstruction/0417/accepted.ttf
```

Технические источники: [совместимость мастеров в Glyphs](https://glyphsapp.com/learn/multiple-masters-part-2-keeping-your-outlines-compatible)
описывает согласование порядка узлов и направляющих;
[fontTools interpolatable](https://fonttools.readthedocs.io/en/latest/varLib/interpolatable.html)
использован для отдельной проверки соответствия контуров и потенциальных изломов.
