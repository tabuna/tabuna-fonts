Пользователь отклонил этот вариант из-за ухудшения рисунка. Основной шрифт — `dist/TabunaSansVariable.ttf`; дальнейшая работа должна сохранять его возможности и качество. Этот каталог — исследование, а не замена продукта. Числа: `build/font-recovery/reports/rejected-full-rebuild.json`.

# Tabuna Sans: собственная модель

Цель — готовый шрифт с **469 символами**, весом **100–900**, оптическим размером
**9–128** и исходными функциями набора. Рабочая сборка пока не заменяет `dist/`.

Сейчас в новой модели есть весь русский и латинский алфавит: 118 запрошенных
букв, дополнительно `0`, `І` и пробел. Один переменный TTF поддерживает вес
100–900. Это восстановление покрытия и диапазона, а не подтверждение качества:
остаются 348 символов, оптическая ось, кернинг и функции подстановки/диакритики.

## Как строятся буквы

- **Чаши и плечи** — собственные кубические кривые. Их определяют габариты,
  положения вершин, соединения и длины касательных. Внешний контур и просвет
  имеют отдельные размеры.
- **Стержни и перекладины** — прямые границы с измеренной толщиной. Одна
  конструкция задаёт семейства `H`, `E/F/L`, `I/T`.
- **Остальной алфавит** — собственные скелеты из прежнего кода проекта:
  многоугольники, чаши и штрихи вдоль кубических осевых линий. Измеряются
  габариты и площадь чёрного; толщина подбирается к площади. Это начальная
  форма для дальнейшей доводки, не точное восстановление рисунка.
- **Акценты** — отдельные две точки или кратка над собственной базовой буквой.
  Совпадающие латинские/кириллические формы могут использовать общий шаблон
  с отдельными боковыми интервалами.

В `alphabet.py` перенесены только собственные конструкции. Ветки с массивами
координат SFNS, переопределения из `refined.py` и переключатели экспериментов
исключены. Происхождение записано в `data/alphabet-provenance.json`.

## Разделение кода и данных

| Файл | Назначение |
| --- | --- |
| `primitives.py` | Семейства чаш, плеч и прямых деталей |
| `alphabet.py`, `drawing.py` | Конструкции полного алфавита и штрихи |
| `data/design.json` | Размеры и параметры мастеров 100/400/800/900 |
| `model.py` | Выбор конструкции и проверка обязательного алфавита |
| `generate_font.py` | Статические TTF, объединение пересечений |
| `build_variable.py` | Совместимое разбиение кривых, gvar/HVAR/STAT, WOFF2 |
| `measure_templates.py` | Измерение и подбор параметров семейств |
| `complete_alphabet.py` | Измеренные габариты и площадь остальных букв |
| `validate.py` | Покрытие и строгая проверка геометрии |
| `compatibility.py` | Сравнение покрытия, осей и функций с исходным шрифтом |

Обычная сборка читает только собственные исходники и `design.json`.
**SFNS.ttf для неё не нужен.** Измерительные команды отдельно используют
локальный системный шрифт; его контуры не экспортируются в модель.

## Сборка и проверки

Из корня репозитория:

```sh
.venv/bin/python -m font_recovery.build_variable --out build/generated-font/tabuna-sans-complete
.venv/bin/python -m font_recovery.generate_font --out build/generated-font/tabuna-sans-complete/static
.venv/bin/python -m font_recovery.validate --font build/generated-font/tabuna-sans-complete/TabunaSansVariable.ttf
.venv/bin/python -m font_recovery.compatibility
.venv/bin/python -m font_recovery.weight_proof
```

Сборщики отказываются выпускать неполный обязательный алфавит. Для отдельного
исследования подмножества нужен явный `--development`. Валидатор сохраняет
все найденные ошибки и завершает работу с ненулевым кодом при их наличии.
Сейчас проверки геометрии переменного файла и совместимости **не проходят**:
полное покрытие букв не отменяет оставшихся проблем.

Полный аудит алфавита:

```sh
./scripts/run-weight-highlight-audit.sh \
  --font build/generated-font/tabuna-sans-complete/TabunaSansVariable.ttf \
  --weights 100,400,900 --sizes 32,64,128 \
  --chars 'ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyzЁАБВГДЕЖЗИЙКЛМНОПРСТУФХЦЧШЩЪЫЬЭЮЯабвгдежзийклмнопрстуфхцчшщъыьэюяё' \
  --verify-repeat --out build/font-recovery/research-v2/audit-alphabet-100-900
.venv/bin/python -m font_recovery.alphabet_proof \
  --audit build/font-recovery/research-v2/audit-alphabet-100-900 --weight 400
```

`weight_proof.py` показывает девять весов из одного TTF через FreeType.
Это демонстрация вариативности. Численное сравнение с эталоном выполняет
отдельный неизменённый CoreText-аудит при общем начале координат и пороге 0.5.

## Условия выпуска

Нужно вернуть все возможности исходного файла, устранить дефекты геометрии,
проверить набор текста и получить улучшение полного исходного raster baseline
без существенных регрессий семейств. Успешная сборка, наличие всех 118 букв или
красивый отдельный образец не заменяют эти требования.
