# Использование Tabuna Sans

## Использование на экране

Для интерфейса начните с веса 400–500, размера 14–18 px и межстрочного
интервала 1.4–1.5. Для абзацев — 16–18 px, вес 400 и интервал 1.6.
Это стартовые настройки: проверьте их на своём экране и содержании.
Вес 100 не рекомендуется для мелкого важного текста: тонкие штрихи
и пунктуация теряют заметность. Вес 900 используйте для коротких акцентов,
а не плотных мелких абзацев. Обе крайности остаются доступны для заголовков.
Отрицательный трекинг предназначен для крупных заголовков; в мелком тексте
используйте `letter-spacing: normal`. Для колонок чисел включите
`font-variant-numeric: tabular-nums` и выравнивание по правому краю.

Текущая сборка 0.0.3 предназначена для пилотного внедрения. Длительное чтение
с участниками и полный набор платформенных проверок ещё не завершены;
универсальная пригодность для чтения с экрана не заявляется.

Набор сохраняет 189 символов. Для произвольного пользовательского текста
оставляйте системный шрифт в цепочке fallback: `•`, `‰`, эмодзи и другие
отсутствующие знаки должны отображаться запасной гарнитурой. Нормализуйте
текст в NFC, если требуется одинаковый результат для составных и готовых
букв: `е` + диакритика и `ё` могут проходить разные пути формирования текста.
В суммах используйте неразрывный пробел, например `12 480,00 ₽`; переносы
и десятичное выравнивание проверяйте на своих реальных значениях.

## Подключение на сайте

Скопируйте WOFF2 в каталог со шрифтами и добавьте:

```css
@font-face {
  font-family: "Tabuna Sans";
  src: url("/fonts/TabunaSansVariable.woff2") format("woff2");
  font-style: normal;
  font-weight: 100 900;
  font-display: swap;
}

body {
  font-family: "Tabuna Sans", system-ui, sans-serif;
  font-optical-sizing: auto;
  font-weight: 400;
}

h1 {
  font-weight: 650;
}
```

Готовый вариант подключения — [dist/tabuna.css](../dist/tabuna.css):
поместите CSS рядом с WOFF2 и примените класс `.tabuna` к нужному элементу.

## Цифры и набор текста

Шрифт содержит кернинг, стандартные лигатуры, контекстные подстановки,
пропорциональные и табличные цифры. Табличные цифры удобны для таблиц,
счётчиков и цен: каждому разряду отводится одинаковая ширина.

```css
.price,
.counter {
  font-variant-numeric: tabular-nums;
}

.prose {
  font-variant-numeric: proportional-nums;
}
```

Не включайте `pnum` и `tnum` одновременно через `font-feature-settings`.
Если приложение задаёт эти низкоуровневые параметры, используйте
`"tnum" 1, "pnum" 0` для табличных цифр. При разной точности сумм
одинаковая ширина цифр сама по себе не выравнивает десятичный разделитель.

В кодах и идентификаторах `O` и `0` различаются преимущественно шириной.
Для критичных кодов выбирайте отдельное оформление с явно различимым нулём
и проверяйте распознавание на своих данных. Шрифт не обещает безошибочного
распознавания произвольных идентификаторов.

Оптический размер обычно выбирается автоматически. Для явного управления:

```css
.caption {
  font-optical-sizing: none;
  font-variation-settings: "opsz" 12;
  font-weight: 400;
}
```
