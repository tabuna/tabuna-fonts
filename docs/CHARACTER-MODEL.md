# Модель авторского характера

Авторские прототипы строятся поверх зафиксированной основы `v0.0.1`.
Модель находится в `scripts/character.py`; `sources/character.json` выбирает
`baseline`, `subtle`, `moderate` или `strong`. Режим `baseline` ничего не меняет.
Выбор прототипа не закрывает автоматически решения D01–D06.

## Направление дуг

Для кубической кривой Безье с точками P₀, P₁, P₂, P₃ длины касательных
регулируются без поворота:

```text
P₁′ = P₀ + λ(P₁ − P₀)
P₂′ = P₃ + λ(P₂ − P₃)
λ = 1 − A · tanh(3(x − ½)) · clamp((y − 0.35)/0.4, 0, 1)
```

Здесь x и y — нормированные координаты середины между концами сегмента.
Слева сверху λ больше единицы, справа — меньше. Положительный множитель
сохраняет направления касательных. В тонких `o/о/O/О/0` сокращение правых
ручек ослаблено на 22% относительно основной формулы; эта поправка плавно
исчезает к весу 400, чтобы верхнее правое плечо не выглядело диагональным. У округлых букв, открытых форм,
плеч, двойных и соединённых чаш разные амплитуды.

Верхний горизонтальный полюс между двумя кривыми и две прилегающие ручки
также сдвигаются вместе вправо на `0.08 · A · ширина`. Одинаковый сдвиг
наружного полюса и полюса просвета защищает толщину. Нижние и боковые
полюса сохраняются; вся буква не наклоняется. Сдвиг применяется только
при горизонтальных сопряжениях двух кубических сегментов.

```text
A = 0.40 · интенсивность · коэффициент семейства
    · (0.42 + 0.58s) · (1 − 0.45h)
s = clamp(log(opsz/9) / log(128/9), 0, 1)
h = clamp((wght − 400)/500, 0, 1)
```

Интенсивности: 0.45, 1.0 и 1.75. Формулы задают исходные мастера;
готовый шрифт интерполирует их через стандартные таблицы OpenType.
Они не вычисляются приложением при показе каждой буквы.

Сохранение направления касательной не доказывает равенство кривизны,
исходную гладкость всех сопряжений или отсутствие пересечений. Для этого
нужны отдельные проверки исходных и скомпилированных контуров.

## Силуэты и оптические поправки

- `I` получает короткие перекладины, ограниченные доступными боковыми
  интервалами; `l` — плавный нижний выход. Ширины набора сохраняются.
- У `c/с` расходятся согласованные наружные и внутренние окончания;
  у `e/е/ё` опускается нижнее окончание. В тяжёлом весе перекладина `e`
  становится немного тоньше. `э/Э` использует согласованное раскрытие.
- `Л/л` укорачивает выход без изменения верхней конструкции; `Д/д`
  согласует начало нижнего перехода. У `Ж/ж`, `К/к`, `Я/я` локальные
  параметры соединения ослабляются по мере увеличения веса.
- Двухэтажная `a`, одноэтажная `g`, флаг `1` и прямые `п/т` сохраняются.

Дизайн-параметры не подбираются по новому совпадению с SF. Их проверяют
по просветам, плавности, интерполяции и повторению характера в строках.
Прототипы, обезличенные сравнения и промежуточные отчёты находятся в
`build/character-prototypes/` и не входят в публичные страницы проекта.

Повторная сборка трёх изолированных вариантов после сохранения основы:

```sh
.venv/bin/python -m font_recovery.build_character_prototypes --out build/character-prototypes/comparison --jobs 3
```

Команда требует нового каталога, проверяет контрольную точку и собирает
TTF/WOFF2 каждого варианта с проверкой `verify.py`. Корневой `dist/`
не изменяется. Сравнение изображений и выбор варианта выполняются отдельно.
