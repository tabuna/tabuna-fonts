# Сборка и локальный просмотр

Из корня репозитория:

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.lock
.venv/bin/python scripts/build.py
.venv/bin/python scripts/test_bezier.py
.venv/bin/python scripts/verify.py
python3 -m http.server 4173 --bind 127.0.0.1
```

Стенд: http://127.0.0.1:4173/. Раздел «Набор символов» показывает все 189 знаков
и имеет отдельный регулятор толщины 100–900.
`./scripts/build-web.sh` также обновляет адреса WOFF2 для кеша браузера.
`python scripts/generate-specimen.py` пересоздаёт иллюстрацию README из TTF.

## Исходники

- `scripts/`: геометрия, сборщик, проверки и калибровочные команды.
- `sources/`: параметры моделей, метрики и явный набор символов.
- `dist/`: TTF, WOFF2, CSS и манифест текущего выпуска.
- `font_recovery/`: измерение, подбор параметров и исследовательские проверки.
- `reports/`: сохраняемый в Git снимок результатов.
- `docs/research/`: исторические отчёты и отклонённые эксперименты.

Обычная сборка использует собственные исходники и не читает SFNS или Inter.
UFO/designspace создаются автоматически. `build/`, `proofs/`, `references/`,
Python-окружения, кеши и сторонние загрузки не входят в Git.

## Проверки

`verify.py` проверяет покрытие, оси, сохранность контуров и функций набора
при компактной сборке, равенство геометрии TTF и WOFF2.

Полный растровый аудит относительно системного шрифта требует macOS:

```sh
.venv/bin/python scripts/audit-full-charset.py
```

Область: 189 символов × 9 весов × 2 размера = 3402 случая. Отдельно
учитываются рисунок, ширина и подмена шрифта. Сырые PNG и промежуточные
кандидаты остаются локально. Проверки не равнозначны доказательству идеального
сходства, полной независимости происхождения или завершённости всех форм.
