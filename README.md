# Tabuna Sans

Компактный вариативный шрифт с латиницей и русской кириллицей.
Одна гарнитура для интерфейсов, заголовков, коротких подписей и числовых данных.
Умеренная гуманистическая пластика, открытые формы и самостоятельная кириллица.
Двухэтажная `a`, одноэтажная `g` и разные силуэты `I/l/1` помогают различать знаки.

## Возможности

| Характеристика | Значение |
|---|---|
| Набор | 189 символов: латиница, русская кириллица с Ё/ё, цифры и знаки |
| Вес `wght` | 100–900, плавно, включая промежуточные значения |
| Оптический размер `opsz` | 9–128 |
| Форматы | Вариативные TTF и WOFF2; WOFF2 около 91 КиБ |
| Набор текста | Кернинг, лигатуры, контекстные подстановки, табличные цифры |
| Начертание | Прямое, без курсива |
| Лицензия | SIL Open Font License 1.1 |

Компактный набор рассчитан на английский и русский текст. Расширенная
латиница, другие кириллические алфавиты и эмодзи не включены; для них
оставляйте системный шрифт в цепочке подстановки.

## Подключение

Скопируйте WOFF2 в каталог `/fonts/` сайта:

```css
@font-face {
  font-family: "Tabuna Sans";
  src: url("/fonts/TabunaSansVariable.woff2") format("woff2");
  font-style: normal;
  font-weight: 100 900;
  font-display: swap;
}

body {
  font-family: "Tabuna Sans", system-ui, sans-serif;
  font-optical-sizing: auto;
  font-weight: 400;
}

.price {
  font-variant-numeric: tabular-nums;
}
```

Или используйте готовый [tabuna.css](dist/tabuna.css) рядом с WOFF2
и класс `.tabuna`. Для установки в системе скачайте TTF.

## На экране

Для интерфейса начните с 14–18 px и веса 400–500; для абзацев — с 16–18 px,
веса 400 и межстрочного интервала 1.6. Крайние веса 100 и 900 оставьте
для крупных акцентов. Проверьте настройки на своём содержании и экране.

**Текущая версия — 0.0.3, пилотная.** Покрытие, вариативность и числовой набор
проверены автоматически. Длительное чтение с участниками и полный набор
платформенных проверок ещё не завершены. Подробности — в
[отчёте о качестве](QUALITY-REPORT.md).

[Рекомендации по использованию](docs/USAGE.md) описывают оптический размер,
табличные цифры, подстановку отсутствующих символов и ограничения.

## Устройство проекта

Шрифт строится из параметрической модели кривых и оптических поправок.
Исходники и параметры находятся в `scripts/` и `sources/`, готовые файлы —
в `dist/`. Обычная сборка не требует SFNS или Inter.
